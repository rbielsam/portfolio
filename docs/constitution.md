# Constitución — Portfolio

Principios innegociables. Toda spec, plan y tarea debe cumplirlos.

1. **Simplicidad primero**: mantener el proyecto sencillo y evitar dependencias, funcionalidades o complejidad innecesarias.

2. **La spec manda**: nada se implementa si no está definido en la spec aprobada. Si falta una decisión o existe una contradicción, se para y se pregunta.

3. **Separación de responsabilidades**: mantener separadas la interfaz, la lógica de negocio y la gestión de datos. El frontend no accede directamente a la base de datos.

4. **Tests como puerta**: las funcionalidades deben validarse mediante las pruebas y comprobaciones definidas. No se avanza si las pruebas requeridas fallan.

5. **Los datos privados están protegidos**: el área de administración requiere autenticación y los datos de contacto y credenciales no deben exponerse públicamente.

6. **Código y documentación mantenibles**: el código debe ser claro y comprensible; el código seguirá las convenciones del proyecto y la documentación se mantendrá actualizada.
